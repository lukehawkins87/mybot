# 6-Day Masterclass Launch Calling Sequence

**Key rules:**
- Double dial = 2 calls back-to-back within a few minutes
- "Newest leads" = any leads that came in since the last calling session
- Leave a message only after the 2nd unanswered call in a session (never after the 1st)
- **Voicemail Script** (SOP 3) — Day 1 only
- **Text/WhatsApp Script 1** (SOP 3) — Days 2–3 for first-time messages
- **Text/WhatsApp Script 2 — Urgency** — from Day 3 onward for any lead who has already received Script 1, and all messages from Day 4 onward
- All non-answerers roll forward and continue being double-dialled every day until they pick up

---

## DAY 1 — 6 Days to Launch

**MORNING**
1. Double dial ALL leads (SOP 3 script)
   - No answer after 2nd call → leave **Voicemail Script** (SOP 3)

**EVENING**
2. Double dial ALL leads again (SOP 3 script)
   - No answer after 2nd call → leave **Voicemail Script** (SOP 3)

---

## DAY 2 — 5 Days to Launch

**MORNING**
1. Double dial newest leads (SOP 3 script)
2. Double dial Day 1 non-answerers (SOP 3 script)

**EVENING**
3. Double dial Day 2 morning non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 1** (SOP 3)

---

## DAY 3 — 4 Days to Launch

**MORNING**
1. Double dial newest leads (SOP 3 script)
2. Double dial Day 2 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 1** (SOP 3)
3. Double dial Day 1 non-answerers — *4th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency** *(already received Script 1)*

**MIDDAY**
4. Double dial all outstanding non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**EVENING**
5. Double dial Day 3 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

---

## DAY 4 — 3 Days to Launch

**MORNING**
1. Double dial newest leads (SOP 3 script)
2. Double dial Day 3 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**
3. Double dial Day 2 non-answerers — *4th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**
4. Double dial Day 1 non-answerers — *6th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**MIDDAY**
5. Double dial all outstanding non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**EVENING**
6. Double dial Day 4 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

---

## DAY 5 — 2 Days to Launch

**MORNING**
1. Double dial newest leads (SOP 3 script)
2. Double dial Day 4 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**
3. Double dial Day 3 non-answerers — *4th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**
4. Double dial Day 2 non-answerers — *6th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**MIDDAY**
5. Double dial Day 1 non-answerers — *8th attempt* (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**EVENING**
6. Double dial Day 5 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

---

## DAY 6 — LAUNCH DAY

**MORNING**
1. Double dial newest leads (SOP 3 script)
2. Double dial Day 5 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**MIDDAY**
3. Double dial ALL remaining non-answerers from any previous day (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**

**EVENING**
4. Double dial Day 6 non-answerers (SOP 3 script)
   - No answer after 2nd call → send **Text/WhatsApp Script 2 — Urgency**
5. Final sweep — double dial any lead that has not picked up at all (SOP 3 script)
