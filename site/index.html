Why your Netlify deploys stopped being automatic

You asked why Claude now hands you an HTML file to upload manually instead of publishing straight to Netlify. Here's what the investigation found, and the two settings that bring automatic deploys back.

Root cause: the environment can't reach Netlify

This Claude session runs in a remote environment whose network policy blocks Netlify's servers. The egress gateway refused connections to both api.netlify.com and netlify-mcp.netlify.app with a policy denial (HTTP 403).

Reading your Netlify account works — that goes through the claude.ai connector — but actually uploading a site runs from inside the environment, hits the blocked hosts, and fails. That's the moment Claude gives up and asks you to upload the file yourself.

Fix 1 — allow Netlify in the environment settings

  1. Open claude.ai/code → Environments and edit the environment your sessions use
  2. In Network access, either allow full network access or add api.netlify.com and *.netlify.app to the allowed domains
  3. Start a new session — deploys upload directly, no manual steps

Fix 2 — stop Netlify holding GitHub deploys for approval

There's a second gate: sites that build from GitHub. Claude's commits are authored as Claude <noreply@anthropic.com> — not a member of your Netlify team — so Netlify parks each build at "Pending approval" until you approve it by hand.

  1. Netlify → Team settings → Access & security → Visitor access
  2. Auto-approve deploys from non-team members → Edit settings → Auto-approve

One-time change, covers every site on the team. No billing downside on the Free plan.

What happened to this very page

Claude tried to deploy this page to Netlify four different ways — the official deploy command, twice, with proxy fixes; a server-side design import; and a Git-based route. Every upload path dead-ended at the blocked hosts, which is exactly the failure you've been living with. So this page shipped as a Claude artifact instead, and it deploys to Netlify the moment Fix 1 is in place.
